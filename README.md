Sales & Revenue Analysis Dashboard

Project Overview

This project focuses on analyzing sales and revenue data using SQL and Power BI. The dashboard provides insights into sales performance, profit trends, regional analysis, and top-performing products through interactive visualizations.

---

Tools & Technologies Used

- SQL
- Power BI
- Excel / CSV
- GitHub

---

Features

- Total Sales KPI
- Total Profit KPI
- Sales by Region Analysis
- Category-wise Revenue Analysis
- Monthly Sales Trend
- Interactive Filters & Slicers
- Product Performance Tracking

---

Dataset Columns

- Order_ID
- Order_Date
- Customer_Name
- Region
- Product
- Category
- Quantity
- Sales
- Profit
- Payment_Mode

---

SQL Concepts Used

- Aggregate Functions
- GROUP BY
- ORDER BY
- SUM()
- COUNT()
- LIMIT

---

Power BI Visualizations

- KPI Cards
- Bar Charts
- Pie Charts
- Line Charts
- Slicers

---

Key Insights

- Electronics category generated highest revenue.
- South region recorded maximum sales.
- UPI payments were used most frequently.
- Monthly sales showed consistent growth.
